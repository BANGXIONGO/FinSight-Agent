# InsightEngine → 社交媒体经济舆情分析智能体改造指南

## 🎯 改造目标

将通用的舆情分析智能体（InsightEngine）改造成专门用于**社交媒体经济舆情分析**的智能体工作流，重点关注：
- 经济政策、市场动态、行业趋势的舆情分析
- 金融指标、经济数据与社交媒体舆情的关联分析
- 投资者情绪、消费者信心等经济心理指标
- 经济事件对市场和社会的影响分析

---

## 📋 需要修改的核心部分

### 1. **提示词系统**（最重要，优先级：⭐⭐⭐⭐⭐）

**文件位置**：`InsightEngine/prompts/prompts.py`

#### 1.1 报告结构生成提示词（`SYSTEM_PROMPT_REPORT_STRUCTURE`）

**当前问题**：通用舆情分析结构，缺乏经济分析维度

**需要修改为**：
```python
SYSTEM_PROMPT_REPORT_STRUCTURE = f"""
你是一位专业的经济舆情分析师和报告架构师。给定一个经济相关的查询，你需要规划一个全面、深入的经济舆情分析报告结构。

**报告规划要求：**
1. **段落数量**：设计5-6个核心段落，每个段落都要有足够的经济分析深度
2. **经济维度**：确保涵盖宏观经济、行业分析、市场情绪、政策影响、投资趋势等维度
3. **数据驱动**：每个段落应该包含可量化的经济指标和社交媒体数据
4. **时间序列**：关注经济舆情的时间演变和趋势

**段落设计原则（经济舆情专用）：**
- **经济事件背景与政策环境**：相关政策背景、经济事件起因、政策时间线、关键经济指标
- **社交媒体经济舆情热度分析**：话题热度、传播路径、平台分布、关键意见领袖（KOL）观点
- **市场情绪与投资者/消费者信心**：情感倾向分析、市场预期、信心指数、风险感知
- **行业与区域差异分析**：不同行业、不同地区、不同收入群体的观点差异
- **经济影响评估与趋势预测**：对实体经济的影响、市场反应、未来趋势预测
- **政策建议与风险提示**：基于舆情分析的政策建议、潜在风险识别

**经济分析深度要求：**
每个段落的content字段应该详细描述：
- 需要分析的经济指标（GDP、CPI、PMI、股市指数等）
- 需要关注的行业和板块
- 需要分析的时间周期（短期、中期、长期）
- 需要对比的历史数据或基准
- 需要引用的社交媒体数据（评论数、转发数、情感分布等）

请按照以下JSON模式定义格式化输出：
...
"""
```

## ⚠️ 注意事项

1. **数据准确性**：经济数据必须准确，否则分析结果会误导
2. **时效性**：经济数据有时效性，需要及时更新
3. **合规性**：使用经济数据API需要遵守相关协议
4. **解释性**：经济分析结果需要可解释，不能只是数据堆砌
5. **风险提示**：经济分析涉及投资建议时，需要添加风险提示
